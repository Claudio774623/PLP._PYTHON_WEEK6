# Assignment: Times Tables, Skip Counting & Loop Hospital

This project practices Python range(), for loops, step values, and debugging common loop errors.

## Files

- `times_table.py` - Generates a times table from 1 to 10 using a for loop and range().
- `skip_counter.py` - Prints even numbers from 0 to 20 and counts down from 10 to 0 using range() steps.
- `loop_hospital.py` - Fixes three common loop problems including an off-by-one error, an infinite loop, and a misplaced accumulator.

## Off-by-One Errors

An off-by-one error happens when a loop runs one time too many or one time too few because the start or stop value is incorrect.

A useful range() habit is to remember that the stop value is not included. I check the starting value and the value just after the last number I want before running my loop.
